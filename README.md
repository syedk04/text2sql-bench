# text2sql-bench

A text-to-SQL agent measured on [BIRD Mini-Dev](https://github.com/bird-bench/mini_dev)
(500 SQLite questions over 11 databases), with a read-only SQL executor and an
execution-accuracy evaluator checked against the official BIRD script.

Status: early. The data loader, executor and evaluator come first, before any
model is called.
